# Vivek Biradar — Updated Personal Portfolio

A responsive, interactive, dark-themed portfolio built with plain HTML, CSS and JavaScript. No build tools or package installation are required.

## Included
- `index.html` — portfolio content and sections
- `style.css` — responsive dark glass-inspired styling and animations
- `script.js` — mobile navigation, scroll progress, reveal effects and card interactions
- `assets/profile.jpg` — the same profile photograph used in the previous portfolio preview
- `assets/Vivek-Biradar-Resume.pdf` — downloadable resume

## Run locally
1. Extract the ZIP.
2. Open the `vivek_portfolio` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.

## Deploy to Netlify
1. Push the contents of this folder to a GitHub repository.
2. In Netlify, choose **Add new site → Import an existing project**.
3. Connect GitHub and select the repository.
4. Leave the build command blank.
5. Set the publish directory to `.`.
6. Deploy.
